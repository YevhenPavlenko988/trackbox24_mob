# Ручний наскрізний сценарій (мобільний + веб)

Перевіряє весь ланцюжок «Нова Пошта → представник → машина → клієнт» разом із офлайн-чергою. Потрібні: запущений бекенд (`trackbox24_back`, `docker compose up -d`), веб (`trackbox24_web`, `npm run dev`), застосунок на емуляторі/пристрої (`flutter run --dart-define=FLAVOR=dev --dart-define=API_BASE_URL=…`, див. README).

## Підготовка (веб, менеджер `manager@test.ua` / `manager123`)

1. **Користувачі**: переконайтесь, що є представник (`rep@test.ua` / `rep12345`) і водій (наприклад `vdrv@test.ua` / `driver123`, роль DRIVER).
2. **Машини**: створіть машину з «Водієм за замовчуванням» = цей водій (без цього водій не зможе створити рейс сам, а менеджер — призначити).
3. **Склади**: хоча б один активний склад.
4. **Рейс**: створіть рейс на цю машину й водія з плановим виїздом сьогодні; у «План» додайте 1–2 отримані посилки (статус «Отримано представником»).

## Представник (застосунок)

5. Увійдіть як `rep@test.ua`. Очікувано: вкладки «Забрати · Отримані · Сканувати · Черга · Ще».
6. «Забрати»: список посилок у Новій Пошті, найближче платне зберігання зверху; рядок із простроченим зберіганням підсвічено.
7. «Сканувати» → режим **Отримати** → введіть/відскануйте три ТТН: одну відому, одну невідому (створиться нова посилка з позначкою «потребує уточнення»), одну з кількома місцями. Зелена картка «Отримано» / «Створено нову посилку та отримано».
8. Відкрийте нову посилку з «Отримані» → «Редагувати»: оберіть клієнта (або створіть нового), заповніть опис, збережіть. У вебі картка посилки має показати ці дані.
9. Режим **На склад**: оберіть склад, відскануйте одну отриману посилку → «Переміщено на склад»; у вебі посилка «На складі» з назвою складу.

## Водій (застосунок)

10. Увійдіть як водій. Очікувано: вкладки «Рейси · Сканувати · Черга · Ще». «Рейси → Заплановані» містить рейс із кроку 4.
11. Картка рейсу: «План» показує заплановані посилки. Натисніть **Завантажити** → відскануйте місця запланованої посилки (`PT…-1`, `PT…-2`) і одну **незаплановану** отриману посилку. Повернувшись, рейс у статусі «Завантаження», у секції «У машині / видано» — усі три, незапланована з позначкою «поза планом», лічильник місць правильний.
12. **Увімкніть режим польоту** й відскануйте ще одне місце. Жовта картка «скан у черзі», на вкладці «Черга» бейдж із кількістю, запис «чекає». Вимкніть режим польоту — за кілька секунд запис стане «відправлено», у картці рейсу місце з'явиться «У машині».
13. **Виїхав** (одометр, напр. 1000). Рейс «У дорозі»; заплановане, але не завантажене знято з плану (історія: «Не завантажено до виїзду»).
14. **Видати**: увімкніть «Отримав оплату від клієнта» лише для посилки, у якої менеджер задав ціну доставки; відскануйте місця. Для посилки без ціни з увімкненою оплатою — червона картка з поясненням бекенду, нічого не змінюється.
15. **Завершити** (одометр ≥ стартового) при посилках, що лишились у машині → діалог показує їх список і просить склад; «На склад і завершити» → рейс «Завершений», у вебі ці посилки «На складі».

## Перевірка у вебі

16. Рейс: статуси, одометри, історія з перекладеними коментарями («Почалося завантаження», «Виїхав, одометр …», «На склад «…»»).
17. Посилки: статуси місць, оплата «Оплачено» після видачі з оплатою, клієнт із кроку 8.
